# 🌐 Website SMK Mitra Industri MM2100

Website resmi SMK Mitra Industri MM2100 yang berfungsi sebagai media informasi sekolah, berita, profil, dan layanan digital untuk siswa maupun masyarakat umum.

---

## 📌 Deskripsi

Project ini merupakan website sekolah berbasis web yang dibangun menggunakan teknologi **HTML, CSS, dan PHP (native)**.  
Website ini bertujuan untuk:
- Menampilkan informasi sekolah
- Menyediakan berita terbaru
- Menampilkan profil dan fasilitas
- Menjadi media komunikasi digital sekolah

---

## ⚙️ Fitur Utama

- 🏫 Halaman Beranda (Home)
- 📰 Halaman Berita
- 📖 Detail Berita
- 🏢 Profil Sekolah
- 📷 Galeri (opsional)
- 📞 Kontak
- 🔐 Dashboard Admin (jika ada)

---

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- PHP Native
- MySQL (Database)
- JavaScript (opsional)
