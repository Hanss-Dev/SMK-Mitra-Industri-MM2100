# 🌐 Website SMK Mitra Industri MM2100

Website resmi SMK Mitra Industri MM2100 yang berfungsi sebagai media informasi sekolah, berita, profil, dan layanan digital untuk siswa maupun masyarakat umum.

---

## 📌 Deskripsi

Project ini merupakan website sekolah berbasis web yang dibangun menggunakan teknologi **HTML, CSS, dan PHP (native)**.

Website ini dibuat untuk:

* Menyediakan informasi resmi sekolah
* Menampilkan berita dan kegiatan terbaru
* Menampilkan profil sekolah dan fasilitas
* Menjadi media komunikasi digital

---

## 🚀 Fitur Utama

* 🏫 Halaman Beranda (Home)
* 📰 Halaman Berita
* 📖 Detail Berita
* 🏢 Profil Sekolah
* 📷 Galeri (opsional)
* 📞 Kontak
* 🔐 Dashboard Admin

---

## 🛠️ Teknologi yang Digunakan

* HTML
* CSS
* PHP Native

* JavaScript (opsional)

---

## 📥 Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/Hanss-Dev/SMK-Mitra-Industri-MM2100
   ```

2. Masukkan ke folder htdocs:

   ```
   C:/xampp/htdocs/
   ```

3. Import database:

   * Buka phpMyAdmin
   * Buat database baru
   * Import file `.sql`

4. Konfigurasi koneksi database:

   ```
   config.php / koneksi.php
   ```

---

## ▶️ Cara Menjalankan

1. Jalankan XAMPP (Apache & MySQL)
2. Buka browser
3. Akses:

   ```
   http://localhost/nama-folder-project
   ```
